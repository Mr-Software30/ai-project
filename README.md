# Kurdistan Job Market Analysis

AI Semester Project — University of Kurdistan Hewler  
Department of Computer Science and Engineering

## What this project does

We collected 240 job listings from [jobs.krd](https://jobs.krd/explore-jobs), a public job board for the Kurdistan Region of Iraq, and applied four machine learning techniques to analyse the data.

## Files

| File | Description |
|------|-------------|
| `ai_project.ipynb` | Main Jupyter notebook with all the code |
| `scrape_jobs_krd.py` | Script used to scrape the data from jobs.krd |
| `jobs_krd.csv` | Raw scraped dataset (240 rows) |
| `jobs_krd_clean.csv` | Cleaned dataset with encoded columns |
| `report.docx` | Written project report |
| `plot1–8.png` | Charts generated by the notebook |

## What we did

- **3.1 Data Preparation** — cleaned the data, encoded text columns, split 80/20 train/test
- **3.2 Regression** — predicted job posting probability from job titles using TF-IDF + Ridge Regression (R² = 0.72)
- **3.3 Classification** — classified jobs as Expired or Active using a Decision Tree (62.5% accuracy)
- **3.4 Clustering** — grouped jobs into 4 clusters using K-Means
- **3.5 Neural Network** — MLP classifier, outperformed the Decision Tree (70.83% accuracy)
